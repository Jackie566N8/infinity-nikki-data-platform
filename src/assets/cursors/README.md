# 大喵光标

为奇迹旅册绘制的 SVG 同人简化插画：黄色兜帽、白色脸部、粉色蝴蝶结。非官方素材。角色大喵及相关形象权利归叠纸游戏 / Infold Games 所有。

- `momo.svg`：普通状态，48 × 48，点击热点 (3, 2)。
- `momo-pointer.svg`：可点击状态，举爪表情，同尺寸与热点。
- 使用原生 CSS cursor，无跟随动画、额外点击层或鼠标移动事件。
- 输入文字保留 text 光标，禁用按钮保留 not-allowed。仅对支持悬停的精细指针设备启用；触屏不显示额外光标。
- 单文件版本把 SVG 内嵌进 CSS，不依赖网络。若浏览器不支持 SVG 光标，则使用系统光标。

## 形象修订与开关
参考用户提供的大喵图片重新绘制矢量头像，未使用截图背景或水印。普通状态为眯眼微笑，悬停为星星眼与双爪。顶部按钮默认开启，选择保存在浏览器的 miraland-momo-cursor-v1 中；文字、提示与辅助阅读标签支持五种语言。
