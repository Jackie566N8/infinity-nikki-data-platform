## 面试问答

| 问题 | 回答要点 |
|---|---|
| 为什么DuckDB？ | 本地嵌入式SQL接CSV/JSON/Python，易复现；SQLite负责关系约束，DuckDB做研究。 |
| 为什么不直接用LLM？ | 当前标签/样本小，关键词与拼音混合可解释、零后端；E不是密集向量或大模型检索。 |
| 97.73%的分母？ | 44有答案中的43命中；50样本其余6无答案另算拒答，Hit@1不是43/50。 |
| F_v2的100%代表泛化吗？ | 不代表，只多修复1条开发q063；已有测试12正例前后均100%，样本有限、非盲审。 |
| 如何防泄漏？ | 原色/进化/改写按家族及意图分组；冻结权重，不把开发样本改成测试；下一轮需新留出集。 |
| 有统计显著性吗？ | 旧候选F−C有50pp但仅4正例家族，组检验p=0.125；不宣称显著。 |
| 群体偏好代表谁？ | 有限来源平台样本，标数量/日期/偏差，不代表全体玩家。 |
| 缺口为何还在？ | 5原色/181进化缺完整确认值，不能全归为未公开；不编造，建议游戏面板实测。 |
| 为何没有最短路线？ | 无验证坐标、传送与通行图，区域推荐与实测模板先行。 |
| 隐私/版权？ | 衣橱库存不上传、遥测关闭；游戏素材外链有网络请求。源码MIT，素材原权利保留。 |
| 如何运行/上线？ | 双击预构建入口；分析用Node24/Python3.12，代码可复现。Pages地址预填，尚未部署。 |
