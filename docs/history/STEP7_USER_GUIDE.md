# 奇迹旅册 · 使用说明

打开“奇迹旅册.html”，或启动源码包的npm start后打开显示的地址。界面支持简体中文、英文、日语、韩语、繁体中文。刷新原已打开的页面可载入本次更新。

图鉴支持名称、昵称、拼音、错字、片段与已收录属性检索；只有足够证据才返回结果。比如神女套→生于无瑕。颜色、元素覆盖有限，不保证复杂视觉描述可检索。

“数据分析”显示来源目录分布；“研究实验室”提供品质×风格关联、聚类及搜索不确定性，解释方法与限制。各表支持CSV/JSON导出；聚类和推荐可点击打开真实套装。

“我的衣橱”与“材料规划”读取浏览器本地标记和库存。整套拥有与逐件拥有分开；来源部件数量有争议时不自动证明集齐。制作和焕新形态分开计算，缺配方目标会跳过并说明。地图只提供区域准备顺序与原文条件，不提供精确路程或传送路线。

“搜索评估”是冻结的候选实验，100条候选真人审核为0，测试集不用于调参。相似推荐得分是目录特征相似度，不是个人喜欢概率。群体偏好只来自4份公开TapTap投票，不代表全体玩家；搜索日志未启用。
