# 奇迹旅册使用说明

双击 `src/index.html` 或交付的“奇迹旅册.html”。五语切换在顶部；大喵光标可开关；暖暖小精灵固定右下角，支持本地资料问答。外链图片需要联网，核心功能本地运行。

图鉴：按品质、风格、类别、获取线索筛选；搜索可用正式名、昵称、拼音、部分名称。结果标明依据；没有足够证据会返回无结果。

衣橱：收藏和已拥有分开标记；只用已拥有计算进度。目标缺件可进入详情。源站部件数量冲突不会自动判为完成。个人标记、材料库存和审核草稿只存在浏览器本地，不上传。

材料规划：有可靠数据的目标可多选，合并材料并扣除库存。66原色制作、93进化资源步骤、191焕新步骤可计算；其余置灰并说明原因。进化的原色副本前置不自动制作；资源和实际副本扣除不能混算。焕新仅计已具备10级后的步骤。鱼按kg，其余按件；未核对数量不补0。区域为备选地点，不是产量分配；没有精确路线。

分析与评估：当前目录是775形态/310原色。数据质量、分析筛选和导出均可追溯。版本日期有来源，历史缺口明确标注。搜索实验100候选/70:30，真人通过0；F部署选择来自开发集，不能将测试100%当作全体用户效果。

最新来源、数据质量和缺口见 [Step8报告](reports/step9/STEP9_FINAL_REPORT.md)。源代码复现见根README；真人审核见 [审核说明](HUMAN_REVIEW.md)，路线录入见 [路线说明](ROUTE_DATA_ENTRY.md)，演示顺序见 [演示脚本](DEMO_SCRIPT.md)。
