# 材料需求规划

## 分析流程

目标选择→套装/部件/配方/材料多表关联→按单位合并需求→扣除本地库存→共同材料标记→区域汇总→CSV导出。

全部775形态可见，350有完整清单可算（66原色、93进化、191焕新）。原色制作候选66/71，直接获取不视为制作目标。不完整条目置灰说明原因；批量跳过提示，CSV注明未纳入目标。

## 公式与单位

相同材料/单位的总需求为目标确认清单之和；缺口=max(总需求−同单位库存,0)。鱼类kg和件数不相加、不擅自换算，精粹、货币等保留来源单位。原色/进化/焕新独立计算，拥有副本前置不自动当消耗，也不自动重制原色。

材料树只沿确认配方展开，缺子配方标待补充，校验拦截周期和不完整清单。五语名称来自对象名称表；库存仅在浏览器本地。

## 来源与区域建议

使用 recipes、recipe_ingredients、outfit_recipe_status、material_guidance 和区域表，前端复用预构建planning数据集。每条保留来源与核对日期，已录入置信度不冒充游戏实测。根 [recipes.csv](../data/recipes.csv) 是配方—原料视图，先筛选status/scope；整套与部件配方不同时加总。

302种可计算清单用料有获取指引，不等于1781材料/道具都有点位。商店、活动、兑换明确标途径。无实测坐标、传送与通行图，**只做区域级建议，不称精确/最短路线**。见 [路线模板](ROUTE_DATA_ENTRY.md)。
